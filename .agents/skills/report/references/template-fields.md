# 결과보고서 원고 칸 채우는 법

양식은 장 네 개(Ⅰ 사업 개요 · Ⅱ 수행 내용 · Ⅲ 성과 · Ⅳ 향후 계획)입니다. `## …` 장 제목 줄은 그대로 둡니다.

| 칸 | 값 |
|---|---|
| 사업명 · 고객사 · 담당자 · 계약금액 | 과업지시서 그대로 |
| 작성일 | 작업일지의 "보고서 작성일" |
| 수행기간 | 작업일지 첫 날짜 ~ 오픈일 |
| 목적 · 범위 | 과업지시서의 과업명·과업 범위를 한 줄씩 |
| 수행 내용 | 항목 · 내용(날짜 포함) · 결과(완료, 수정 횟수) |
| 성과 | 지표 · 목표 · 실적 · 비고. 목표가 작업일지에 없으면 `리뉴얼 전` 값을 비교 기준으로 적고, 그것도 없으면 `-` |
| 유지보수 · 후속 제안 | 작업일지 "다음 할 일" |
