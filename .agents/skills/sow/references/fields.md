# 과업지시서 원고 칸 채우는 법

| 칸 | 값 |
|---|---|
| 과업명 | 견적서 건명 |
| 작성일 | 오늘 날짜, `2026. 10. 30.` 모양 |
| 발주처 · 담당자 | 견적서 고객사 · 담당자 그대로 |
| 과업기간 | `오늘 ~ 희망 오픈일` (예: `2026. 10. 30. ~ 2026. 11. 30.`) |
| 계약금액 | 견적서 합계 + ` (부가세 포함)` |
| 과업 범위 | 견적서 품목마다 한 줄: 과업 내용 · 산출물 · 비고(수량) |
| 추진 일정 | 기획 → 디자인 → 개발 → 검수 순으로 과업기간을 나눈다. 오픈은 희망 오픈일 하루 |
| 납품물 | 산출물을 쉼표로 |
| 검수 방법 | `오픈 전 고객 확인 후 수정 2회 반영` |
| 하자보수 | `오픈 후 3개월 무상` |
| 특기사항 | 견적서 비고에서 제외·확인 필요 항목 |
