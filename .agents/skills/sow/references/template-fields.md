# 과업지시서 원고 쓰는 법

`node scripts/hwpx.js draft sow {고객코드}`가 만든 틀(templates/sow-outline.md)의 ( ) 자리를 모두 채운다. 장 제목(`## …`)과 목차 표는 그대로 둔다. 분량·문장은 [writing-guide.md](writing-guide.md), 품목 묶기는 [task-mapping.md](task-mapping.md).

| 부분 | 무엇을 | 어디서 |
|---|---|---|
| 맨 위 정보 | 과업명 · 작성일 · 발주처 · 수행사 · 과업기간 · 계약금액 | 견적서 건명·고객사·합계, `data/company.md` 상호, 요청 기록 `sow.start` ~ `open`(납기) |
| Ⅰ 과업 개요 | 배경 · 목적 한두 문장 + 개요 표(담당자 · 책임자 포함) | 요청 기록 `sow.reason`(이번 일을 하는 이유), 없으면 업종 일반 수준 + "확인 필요" |
| Ⅱ 과업 내용 | 전체 개요 표(과업 · 주요 내용 · 관련 견적 품목) → 과업마다 `### 과업 N. 이름` 블록 → 마지막 `### 기대효과` | 견적서 품목, 요청 기록 `sow.must`(꼭 들어갈 요구사항) |
| 과업 블록 | 개요 · 현재/개선 표 · 목적 (가)(나)(다) · 범위 표 · 요구사항 표 4행 이상 · 주 산출물(예시) 2~3개 | 위와 같음 |
| Ⅲ 추진 일정 | 과업마다 한 줄 + `검수·납품`. 열은 착수일부터 납기까지 주(1주, 2주 …), 하는 주에 ■ | 요청 기록 |
| Ⅳ 최종 산출물 | 번호 · 산출물 · 형태 · 관련 과업 · 제출 시점 | Ⅱ의 주 산출물 |
| Ⅴ 검수 계획 | 검수 항목 표 3행 이상(항목 · 기준 · 방법) + 하자보수 · 보안 · 저작권 · 자료 제공 · 특기사항 | `data/company.md` 계약 조건. 없으면 "확인 필요" |

과업 블록은 과업 수만큼 복사하고, 표의 줄은 필요한 만큼 늘린다.
