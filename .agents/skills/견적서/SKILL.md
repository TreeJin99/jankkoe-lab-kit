# 견적서 만들기 (5단계)

명령의 `kordoc`이 없다고 나오면 `npx -y kordoc`으로 바꿔 씁니다. (Node.js 20 이상 필요)

## 1. 메일 읽기
`받은메일/` 폴더의 메일을 읽고 아래를 적어 둡니다.
- 고객사, 담당자(이름과 직함 그대로), 요청 내용, 희망 오픈일

## 2. 품목 뽑기
요청 내용을 `자료/단가표.md`의 품목으로 바꿉니다.
- 페이지: 메인 1개는 W-02, 나머지는 W-03으로 개수만큼
- 휴대폰 대응 요청 → W-04 / 직접 글 올리는 게시판 → W-05 / 방문자 문의 → W-06
- 기존 글·사진 옮기기 → W-07, 옮길 페이지 수만큼
- 기획·화면설계(W-01)는 항상 1식 넣습니다.
- 고객이 이미 가진 것(예: 도메인·호스팅)은 뺍니다.

## 3. 단가표 대조·계산
- 단가는 단가표 값 그대로. 금액 = 단가 × 수량
- 공급가액 = 금액 합 / 부가세 = 공급가액 × 0.1 (원 단위 아래 버림) / 합계 = 공급가액 + 부가세
- 계산은 명령으로 확인합니다: `python3 -c "print(800000+600000)"`

## 4. 양식 채우기 (kordoc)
① 양식을 원고(마크다운)로 꺼냅니다.
```bash
kordoc 양식/견적서.hwpx --keep-layout-tables --keep-empty-cols --silent -o 결과/_원고.md
```
② `결과/_원고.md`에서 비어 있는 칸(`|  |`)만 채웁니다.
- 제목·표의 줄 수·이미 적힌 글자는 건드리지 않습니다. 품목이 8개보다 적으면 남는 줄은 번호만 두고 비웁니다.
- 견적일자: 오늘 날짜 / 견적번호: `Q-오늘날짜-01` (예: `Q-20261030-01`) / 건명: 예) `홈페이지 리뉴얼`
- 단가·금액 칸은 숫자만 쉼표로 (예: `250,000`). 공급가액·부가세·합계 칸은 끝에 `원` (예: `4,950,000원`)
- 비고: `부가세 별도. 오픈 희망일 2026. 11. 30.`처럼 한 줄

③ 원고를 양식에 넣어 저장합니다.
```bash
kordoc patch 양식/견적서.hwpx 결과/_원고.md -o 결과/견적서_바다상사.hwpx
```
- 출력에 `skipped`(건너뜀)가 있으면 원고를 고쳐 다시 합니다.
- 잘 들어갔는지 읽어 봅니다: `kordoc 결과/견적서_바다상사.hwpx`
- 확인이 끝나면 원고를 지웁니다: `rm 결과/_원고.md`

## 5. 검수
검수담당에게 결과 파일 경로를 주고 확인을 맡깁니다. "돌려보냄"이 오면 4단계부터 고쳐서 다시 맡깁니다. 통과하면 파일 이름과 합계만 알려 줍니다.
