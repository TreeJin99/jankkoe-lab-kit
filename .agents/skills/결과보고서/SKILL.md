# 결과보고서 만들기 (5단계)

명령의 `kordoc`이 없다고 나오면 `npx -y kordoc`으로 바꿔 씁니다. (Node.js 20 이상 필요)

## 1. 자료 읽기
```bash
kordoc 결과/과업지시서_바다상사.hwpx
```
그리고 `자료/작업일지_바다상사.md`를 읽습니다. 사업명·고객사·담당자·계약금액은 과업지시서에서, 한 일과 숫자는 작업일지에서 가져옵니다.

## 2. 수행 내용 뽑기
과업지시서의 과업 한 줄마다 작업일지에서 "실제로 한 일"과 "결과(완료·변경)"를 찾아 짧게 적습니다. 6줄을 넘으면 비슷한 것끼리 묶습니다.

## 3. 대조
- 성과 표의 실적 숫자는 작업일지에 적힌 숫자만 씁니다. 없으면 `확인 필요`.
- 계약금액·고객사·담당자는 과업지시서와 똑같은지 봅니다.
- 작성일은 작업일지의 "보고서 작성일"을 씁니다.

## 4. 양식 채우기 (kordoc)
```bash
kordoc 양식/결과보고서.hwpx --keep-layout-tables --keep-empty-cols --silent -o 결과/_원고.md
```
`결과/_원고.md`의 빈칸(`|  |`)만 채웁니다. 제목·줄 수·이미 적힌 글자는 그대로 둡니다.

```bash
kordoc patch 양식/결과보고서.hwpx 결과/_원고.md -o 결과/결과보고서_바다상사.hwpx
kordoc 결과/결과보고서_바다상사.hwpx
rm 결과/_원고.md
```
출력에 `skipped`가 있으면 원고를 고쳐 다시 합니다.

## 5. 검수
검수담당에게 결과보고서·과업지시서·작업일지 경로를 주고 숫자 대조를 맡깁니다. 통과하면 파일 이름만 알려 줍니다.
