# 과업지시서 만들기 (5단계)

명령의 `kordoc`이 없다고 나오면 `npx -y kordoc`으로 바꿔 씁니다. (Node.js 20 이상 필요)

## 1. 견적서 읽기
```bash
kordoc 결과/견적서_바다상사.hwpx
```
고객사·담당자·건명·품목·합계를 적어 둡니다. 희망 오픈일은 `받은메일/`의 메일에서 확인합니다.

## 2. 과업 뽑기
견적서 품목 하나가 과업 한 줄입니다. 품목마다 "무엇을 하는지"와 "무엇을 넘겨주는지(산출물)"를 짧게 적습니다.
- 예) 기획·화면설계 → 과업 내용 `사이트 구조·메뉴·화면 배치 설계` / 산출물 `화면설계서`

## 3. 견적서와 대조
- 과업명 = 견적서 건명, 발주처·담당자 = 견적서 그대로
- 계약금액 = 견적서 합계에 `(부가세 포함)`을 붙입니다. 예) `5,445,000원 (부가세 포함)`
- 과업기간 = 오늘 날짜 ~ 희망 오픈일. 일정 5단계(기획·디자인·개발·검수·오픈)를 이 안에 나눕니다. 오픈은 희망 오픈일 하루.

## 4. 양식 채우기 (kordoc)
```bash
kordoc 양식/과업지시서.hwpx --keep-layout-tables --keep-empty-cols --silent -o 결과/_원고.md
```
`결과/_원고.md`의 빈칸(`|  |`)만 채웁니다. 제목·줄 수·이미 적힌 글자는 그대로 둡니다. 남는 줄은 번호만 두고 비웁니다.
- 납품물: 산출물을 쉼표로 나열 / 검수 방법: 예) `오픈 전 고객 확인 후 수정 1회 반영` / 하자보수: 예) `오픈 후 3개월 무상` / 특기사항: 예) `도메인·호스팅은 고객 보유분 사용`

```bash
kordoc patch 양식/과업지시서.hwpx 결과/_원고.md -o 결과/과업지시서_바다상사.hwpx
kordoc 결과/과업지시서_바다상사.hwpx
rm 결과/_원고.md
```
출력에 `skipped`가 있으면 원고를 고쳐 다시 합니다.

## 5. 검수
검수담당에게 과업지시서와 견적서 경로를 주고 금액·고객명·날짜 대조를 맡깁니다. 통과하면 파일 이름만 알려 줍니다.
