# 메일 요청 → 단가표 품목

| 메일에 이런 말이 있으면 | 코드 | 수량 |
|---|---|---|
| (항상) | W-01 기획·화면설계 | 1 |
| 메인 페이지 | W-02 | 1 |
| 메인을 뺀 나머지 페이지 | W-03 | 페이지 수 |
| 휴대폰·모바일·태블릿 | W-04 | 1 |
| 직접 글 올리는 게시판(공지·뉴스) | W-05 | 1 |
| 방문자 문의를 메일로 받기 | W-06 | 1 |
| 예전 글·사진 옮기기 | W-07 | 옮길 페이지 수 |
| 새 도메인·호스팅 필요 | W-08 | 1 |

- 고객이 이미 가진 것(예: "도메인·호스팅은 지금 것 사용")은 넣지 않는다.
- 단가표에 없는 요청(결제, 회원가입, 예약 등)은 품목 표에 넣지 않고 비고에 `○○ 기능은 단가 확인 필요`로 적는다.
- 페이지 수가 메일에 없으면 묻지 말고 비고에 `페이지 수 확인 필요`로 적고, 아는 것만 넣는다.
