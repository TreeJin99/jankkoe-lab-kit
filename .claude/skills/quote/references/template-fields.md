# 견적서 원고 칸 채우는 법

| 칸 | 값 |
|---|---|
| 견적일자 | 오늘 날짜, `2026. 10. 30.` 모양 |
| 견적번호 | `Q-오늘날짜-01` (예: `Q-20261030-01`) |
| 고객사 · 담당자 | 메일에 적힌 글자 그대로 (예: `이수진 과장`) |
| 용역명 | 요청을 한 줄로 (예: `홈페이지 리뉴얼`) |
| 품목 표 | `calc.js`가 낸 줄 그대로. 단가·금액은 숫자와 쉼표만 |
| 공급가액 · 부가세(10%) · 합계 | `calc.js` 값 끝에 `원` (예: `4,950,000원`) |
| 비고 | `부가세 별도.` + 희망 오픈일 + 제외한 것 · 확인 필요한 것 한 줄 |

이미 적힌 칸(유효기간·상호·대표·등록번호·연락처·주소·업태)과 표 줄 수, `## 견적 내역` 같은 장 제목 줄은 그대로 둔다. 품목이 8개보다 적으면 남는 줄은 번호만 둔다.
