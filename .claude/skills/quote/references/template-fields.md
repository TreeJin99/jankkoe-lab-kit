# 견적서 원고 칸 채우는 법

| 칸 | 값 |
|---|---|
| `(고객사) 귀하` 줄 | `바다상사 귀하`처럼 요청 기록 `customer` + ` 귀하` |
| 견적일자 | 요청 기록 `date` (`2026. 10. 30.` 모양) |
| 견적번호 | `Q-견적일-01` (예: `Q-20261030-01`) |
| 고객사 · 담당자 · 건명 | 요청 기록 `customer` · `contact` · `service` 글자 그대로 |
| 납기 · 결제 조건 | 요청 기록 `open` · `payment`. 없으면 `확인 필요` |
| 합계금액 | `calc.js`가 낸 줄 그대로: `일금 오백사십사만오천원정 (₩5,445,000, 부가세 포함)` |
| 상호 · 등록번호 · 연락처 · 주소 · 업태 | `data/company.md` 값 그대로 (등록번호 = 사업자번호, 업태 = 업종). 비어 있으면 `확인 필요` |
| 대표 | `data/company.md` 대표 + ` (인)` (예: `홍길동 (인)`). 도장 이미지는 넣지 않는다 |
| 품목 표 | `calc.js`가 낸 줄 그대로. 단가·금액은 숫자와 쉼표만 |
| 공급가액 · 부가세(10%) · 합계 | `calc.js` 값 끝에 `원` (예: `4,950,000원`) |
| 비고 | `부가세 별도.` + 요청 기록 `note` 한 줄 |

이미 적힌 칸(유효기간)·표 줄 수·`## 견적 내역` 장 제목 줄·"아래와 같이 견적합니다." 문장은 그대로 둔다. 품목이 8개보다 적으면 남는 줄은 번호만 둔다.
