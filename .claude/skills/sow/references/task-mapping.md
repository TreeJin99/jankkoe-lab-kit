# 견적 품목 → 과업 묶기

1. 같은 목적의 품목은 한 과업으로 묶는다. 과업은 2~5개가 알맞다.
   - 예(웹): 기획·화면설계 → 과업 1 / 메인·서브 디자인·제작·반응형 → 과업 2 / 게시판·문의폼·콘텐츠 이전 → 과업 3
   - 예(제조): 시제품 설계 → 과업 1 / 금형·가공 → 과업 2 / 양산·검사 → 과업 3
   - 예(교육): 커리큘럼 설계 → 과업 1 / 강의 운영 → 과업 2 / 평가·결과 정리 → 과업 3
2. 과업 이름은 품목 이름을 줄여서 쓴다. 견적에 없는 일을 새로 만들지 않는다.
3. 과업마다 주 산출물(예시) 1~3개: 그 과업이 끝나면 넘겨주는 것(문서 · 파일 · 실물). 형태는 PDF · 원본 파일 · 실물 납품 · 서버 설치 등.
4. 범위에는 견적서 수량을 그대로 쓴다(예: "서브 7페이지", "부품 100개", "강의 3회").
