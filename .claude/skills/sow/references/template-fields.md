# 과업지시서 원고 칸 채우는 법

양식은 장 다섯 개(Ⅰ 과업 개요 · Ⅱ 과업 범위 · Ⅲ 최종 산출물 · Ⅳ 추진 일정 · Ⅴ 검수 및 하자보수)입니다. `## …` 장 제목 줄과 이미 적힌 칸(일정의 단계 이름)은 그대로 둡니다.

| 장 | 칸 | 값 |
|---|---|---|
| Ⅰ | 과업명 | 견적서 용역명 |
| Ⅰ | 작성일 | 오늘 날짜, `2026. 10. 30.` 모양 |
| Ⅰ | 발주처 · 담당자 | 견적서 고객사 · 담당자 그대로 |
| Ⅰ | 수행사 · 책임자 | `data/company.md` 상호 · 대표 |
| Ⅰ | 과업기간 | `요청 기록 sow.start ~ 오픈 희망일` (예: `2026. 10. 30. ~ 2026. 11. 30.`) |
| Ⅰ | 계약금액 | 견적서 합계 + ` (부가세 포함)` |
| Ⅱ | 과업 내용 · 비고 | 견적서 품목마다 한 줄. 무엇을 하는지 짧게, 비고는 수량(예: `7페이지`) |
| Ⅲ | 산출물 · 납품 형태 | 넘겨줄 것 4개 이내 (예: `화면설계서` · `PDF`, `홈페이지 소스` · `서버 설치`) + 요청 기록 sow.deliverables |
| Ⅳ | 할 일 · 기간 | 기획 → 디자인 → 개발 → 검수 순으로 과업기간을 나눈다. 오픈은 희망 오픈일 하루 |
| Ⅴ | 검수 방법 | `오픈 전 고객 확인 후 수정 2회 반영` (data/company.md 계약 조건) |
| Ⅴ | 하자보수 | `오픈 후 3개월 무상` (data/company.md 계약 조건) |
| Ⅴ | 특기사항 | 견적서 비고에서 제외·확인 필요 항목 |
