# 과업지시서 원고 쓰는 법

`node scripts/hwpx.js draft sow {고객코드}`가 만든 틀(templates/sow-outline.md)의 ( ) 자리를 채운다. 장 제목(`## …`)과 목차 표는 그대로 둔다. 다 쓰면 `fill`이 견본(templates/sow.hwpx) 서식으로 새로 만든다.

| 장 | 무엇을 | 어디서 |
|---|---|---|
| Ⅰ 과업 개요 | 과업명 · 작성일 · 발주처 · 담당자 · 수행사 · 책임자 · 과업기간 · 계약금액 | 견적서 건명·고객사·담당자·합계, `data/company.md` 상호·대표, 요청 기록 `sow.start` ~ `open`(납기) |
| Ⅱ 과업 내용 | `### 과업 N. 이름` 블록을 과업 수만큼. 블록마다 `- 목적:` `- 범위:` `- 요구사항:` 한 줄씩 + 주 산출물(예시) 표 1~3줄 | 견적서 품목을 [task-mapping.md](task-mapping.md) 규칙으로 묶는다 |
| Ⅲ 추진 일정 | 과업마다 한 줄 + 마지막 `검수·납품` 줄. 열은 착수일부터 납기까지 주(1주, 2주 …), 하는 주에 ■ | 요청 기록 `sow.start` ~ `open` |
| Ⅳ 최종 산출물 | Ⅱ의 주 산출물을 모아 번호 · 산출물 · 형태 · 관련 과업 | Ⅱ |
| Ⅴ 검수 계획 및 하자보수 | 검수 방법 · 하자보수 · 특기사항 | `data/company.md` 계약 조건. 없으면 `확인 필요` |

문장은 짧게 명사형으로(예: "기준 수립", "화면 제작"). 결과로만 알 수 있는 수치·화면·주소는 쓰지 않는다(과업지시서는 할 일을 정하는 문서).
