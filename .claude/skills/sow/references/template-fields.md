# 과업지시서 원고 쓰는 법

`node scripts/hwpx.js draft sow {고객코드}`가 만든 틀(templates/sow-outline.md)의 ( ) 자리를 모두 채운다. 장 제목(`## …`)과 목차 표, `(과업명)` 같은 목록 라벨은 그대로 둔다. 구조·분량·문장은 [writing-guide.md](writing-guide.md), 품목 묶기는 [task-mapping.md](task-mapping.md).

| 부분 | 무엇을 | 어디서 |
|---|---|---|
| 표지 | 과업명 · 작성일 · 발주처 · 대표자명 · 수행사 · 서명 (인) | 견적서 건명·고객사, `data/company.md` 상호·대표. 발주처 대표자 이름을 모르면 "확인 필요" |
| 1. 위탁회사 현황 및 실적 | 기업체명 · 대표자 · 설립일자 · 사업자등록번호 · 소재지 · 연락처 · 업종(주제품) · 연혁 및 실적 | `data/company.md`. 없는 칸은 "확인 필요" |
| 2.1 과업 개요 | 2~3문장 + (과업명)(발주처)(수행기관)(과업 기간)(과업 금액) | 견적서, 요청 기록 `sow.reason`·`sow.start`·`open`. 과업 금액은 견적서 합계금액 줄 그대로 |
| 2.2 과업별 내용 | `### 과업 N. 이름` 블록을 과업 수만큼: 1) 과업 개요 · 2) 과업 목적 (가)(나)(다) · 3) 과업 범위(내용) 표 · 4) 산출물 예시 표 + 그림 | 견적 품목, 요청 기록 `sow.must` |
| 3. 과업 추진일정 | 과업마다 한 줄 + `통합 점검, 최종 산출물 납품 및 검수`. 열은 착수일부터 납기까지 주차, 하는 주에 ■ | 요청 기록 |
| 4. 최종 산출물 | 번호 · 산출물 · 수량 · 형태 · 비고(관련 과업) | 2.2의 주 작업물 |
| 5. 검수 계획 | 1) 검수항목 표 3행 이상(□ 적정 / □ 부적정) · 2) 검수(테스트) 방안 (1)(2)… · 하자보수 · 보안 · 저작권 · 자료 제공 | `data/company.md` 계약 조건. 없으면 "확인 필요" |

## 산출물 예시 그림 (과업마다 1장)
- 기본: `node scripts/mockup.js <종류> outputs/_draft/img/task{N}.png`. 종류 = `screen`(화면·웹·앱) · `doc`(문서·보고서) · `video`(영상) · `print`(인쇄물) · `product`(제품·시제품) · `other`.
- `data/참고이미지/`에 사용자가 넣은 이미지가 있으면 그걸 쓰고, 출처를 메인 대화가 물어 캡션에 붙인다.
- 그림 줄 바로 아래 캡션 `예시 이미지 · 실제 결과물 아님`은 지우지 않는다. 인터넷 이미지는 내려받지 않는다.
