# 잔꾀 연구소 실습 킷

「견적서 만들어줘」라고 말하면 AI가 고객사·품목·날짜를 **되물어 확인한 뒤** 견적서 → 과업지시서를 한글(hwpx) 파일로 만들고, 금액을 스스로 검산합니다.
우리 회사 정보가 없으면 먼저 물어봅니다. 처음이라면 예시 회사 「새벽웹스튜디오」로 해 볼 수 있습니다.

> 회사·고객·금액·연락처는 모두 실습용 가상 정보입니다.

---

## 1. 받기

**방법 A. ZIP으로 받기 (처음이면 이쪽)**
1. 이 페이지 위쪽 초록색 **Code** 버튼을 누릅니다.
2. 맨 아래 **Download ZIP**을 누릅니다.
3. 받은 ZIP 파일을 풀면 `jankkoe-lab-kit-main` 폴더가 생깁니다.

**방법 B. git으로 받기**
```bash
git clone https://github.com/TreeJin99/jankkoe-lab-kit.git
```

## 2. 준비

| 필요한 것 | 확인 방법 |
|---|---|
| Claude 데스크톱 앱 (Pro 이상) 또는 Claude Code | 앱 왼쪽 위에 **Code** 탭이 보이면 됩니다 |
| Node.js 20 이상 | 아래 첫 줄. 없으면 https://nodejs.org 에서 LTS 설치 |
| 한글 문서 도구 kordoc | 아래 둘째 줄. 처음 한 번은 내려받느라 시간이 조금 걸립니다 |
| (윈도우만) Git for Windows | Claude Code가 윈도우에서 쓰는 도구입니다. 없으면 https://git-scm.com 에서 설치 |

```bash
node -v
npx -y kordoc --version
```
`v20` 이상, 그리고 `4.` 으로 시작하는 숫자가 나오면 준비 끝입니다.

## 3. 열기

1. Claude 앱에서 **Code** 탭을 누릅니다.
2. 폴더 선택에서 받은 `jankkoe-lab-kit` 폴더를 고릅니다.
3. "이 폴더를 신뢰하나요?"가 나오면 **신뢰**를 누릅니다. 그래야 아래 명령을 매번 묻지 않고 실행합니다.

## 4. 실습: 이 문장 그대로 입력

**① 견적서**
```text
견적서 만들어줘
```
AI가 먼저 어떻게 일할지 3줄로 알려 주고, 질문 창을 띄웁니다.
1. 회사 정보가 비어 있으면: **「예시 회사(새벽웹스튜디오)로 먼저 해 보기」**를 고르면 바로 시작합니다. 우리 회사로 하려면 정보를 입력합니다(다음부터는 다시 묻지 않음).
2. 고객사 · 담당자 · 용역명 · 품목과 수량 · 견적일 · 오픈 희망일 · 비고를 묻습니다. 고르거나 직접 입력합니다.
3. 요약을 보여 주고 "이대로 만들까요?"를 묻습니다. 확인하면 견적 담당이 쓰고, 검수 담당이 확인합니다.

연습용 답: 고객사 `바다상사`, 담당자 `이수진 과장`, 용역 `홈페이지 리뉴얼`, 품목 기획 1 · 메인 1 · 서브 7 · 반응형 1 · 게시판 1 · 문의폼 1 · 콘텐츠 이전 8, 오픈 `2026-11-30`
→ 합계 **5,445,000원** (공급가액 4,950,000원 + 부가세 495,000원)

**② 과업지시서**
```text
방금 견적서로 과업지시서 만들어줘
```
견적서 내용을 이어받고, 빠진 것(시작일 · 산출물 추가)만 묻습니다.

`outputs/`에 `quote_badasangsa.hwpx`(견적서) · `sow_badasangsa.hwpx`(과업지시서)가 생기면 성공입니다. 한글(한컴오피스)로 열어 보세요.

**질문 없이 한 번에** (값을 다 말하면 다시 묻지 않습니다)
```text
견적서 만들어줘. 예시 회사로, 고객사 바다상사 이수진 과장, 홈페이지 리뉴얼, 기획 1 · 메인 1 · 서브 7 · 반응형 1 · 게시판 1 · 문의폼 1 · 콘텐츠 이전 8, 견적일 오늘, 오픈 2026-11-30
```

## 5. 더 해 보기

**슬래시 명령** (레시피를 바로 부르기)
```text
/quote
```
```text
/sow
```

**팀원(에이전트) 부르기**
```text
reviewer한테 outputs 폴더 검사시켜
```

**규칙·자료 바꾸기**
```text
단가표에 "SNS 연동 1식 300,000원" 품목 하나 추가해줘
```
```text
앞으로 견적서 유효기간은 30일로 CLAUDE.md에 추가해
```

**다른 고객으로 해 보기**
```text
푸른제과 쇼핑몰 견적서 만들어줘. 카드 결제 기능도 넣어줘
```
단가표에 없는 품목(카드 결제)은 단가를 묻고, 단가표에 추가할지 확인합니다.

**우리 회사 양식으로 바꾸기**
1. 우리 회사 견적서 hwpx를 `templates/quote.hwpx` 이름으로 덮어씁니다. (원래 파일은 따로 보관)
2. 이렇게 말합니다.
```text
templates/quote.hwpx 양식이 바뀌었어. 견적서 레시피의 칸 채우는 법을 새 양식에 맞게 고쳐줘
```

### 어떻게 작동하나
1. **회사 규칙**(`CLAUDE.md`)을 먼저 읽습니다. 모르는 값은 지어내지 말고 물어보라는 규칙이 여기 있습니다.
2. **매뉴얼**(스킬 `quote`·`sow`)대로 질문 → 요약 확인 → 요청 기록 저장 순서로 갑니다. 질문은 메인 대화만 합니다.
3. **팀**(에이전트)에게 나눠 맡깁니다. 견적 담당이 쓰고 검수 담당이 확인합니다.
4. 파일이 저장되면 **자동 검산**(훅)이 요청 기록과 대조하고, 틀리면 고칠 때까지 다시 합니다.

**ChatGPT Codex에서 쓰기**
같은 폴더를 Codex로 열면 `AGENTS.md`와 `.agents/skills/`를 읽습니다. 레시피는 `$quote` · `$sow`로 부릅니다.

## 6. 폴더 안에 있는 것

| 하네스 요소 | 위치 | 하는 일 |
|---|---|---|
| 회사 규칙 | `CLAUDE.md` | AI가 일하기 전에 먼저 읽는 규칙 (모르면 묻기, 부가세 별도, 파일 이름, 금지 정보) |
| 회사 규칙 (Codex용) | `AGENTS.md` | `CLAUDE.md`와 같은 내용 |
| 룰 | `.claude/rules/templates.md` | `templates/`·`outputs/` 파일을 만질 때만 읽는 한글 양식 규칙 |
| 레시피 (스킬) | `.claude/skills/quote · sow` | 문서별 작성 단계와 위임 순서. 세부는 `references/`, 시험은 `evals/` |
| 레시피 (Codex용) | `.agents/skills/` | 같은 내용 |
| 팀 (에이전트) | `.claude/agents/` | quote-writer 견적담당 · doc-writer 문서담당 · reviewer 검수담당 |
| 자동 검산 (훅) | `.claude/hooks/check-outputs.js` | `outputs/`에 hwpx가 저장되면 바로 검산. 틀리면 AI에게 돌려보내 고치게 함 |
| 권한 · 훅 설정 | `.claude/settings.json` | 실습 명령은 묻지 않고 실행, 위험한 명령(`rm -rf` 등)은 막음 |
| 계산 · 양식 · 검산 도구 | `scripts/` | `calc.js` 금액 계산 · `hwpx.js` 양식 채우기 · `check.js` 검산 · `run-evals.js` 스킬 평가 |
| 우리 회사 정보 | `data/` | `company.md` 회사 정보 · `prices.md` 단가표 (처음엔 빈 칸, AI가 물어서 채움) |
| 양식 | `templates/` | 한글 양식 2종 (빈칸) |
| 결과 | `outputs/` | 완성 문서 (`문서_고객코드.hwpx`) · 확정된 요청 기록 `_requests/고객코드.json` |
| 예시 회사 | `examples/saebyeok/` | 「새벽웹스튜디오」(가상) 회사 정보 · 단가표 |

### 스킬 구조 (예: `.claude/skills/quote/`)

| 파일 | 하는 일 |
|---|---|
| `SKILL.md` | 이름·설명(언제 쓰나)·허용 도구 + 짧은 단계. 누가 작성하고 누가 검수하는지 |
| `references/questions.md` | 무엇을 어떤 선택지로 물을지 · 요청 기록 형식 (quote만) |
| `references/template-fields.md` | 양식 칸마다 무엇을 채우는지 |
| `references/kordoc-commands.md` | 명령 모음과 오류 대처 |
| `evals/evals.json` | 잘 되는지 보는 시험 3~4건 (입력 문장 · 준비 파일 · 기대 결과 · 실패 기준) |
| `evals/trigger-evals.json` | 이 스킬을 써야 하는 문장 / 쓰면 안 되는 문장 |
| `evals/fixtures/` | 시험용 원고 (sow만: 미리 만들어 둔 견적서 · 요청 기록) |

계산·양식·검산 도구는 두 스킬이 같이 쓰므로 스킬 폴더가 아니라 맨 위 `scripts/`에 한 벌만 둡니다.
평가는 `node scripts/run-evals.js`(트리거는 `--trigger`)로 돌립니다. Claude 사용량이 드니 킷을 고칠 때만 쓰세요.

### 자동 검산이 하는 일
AI가 `outputs/`에 hwpx를 저장하면 `scripts/check.js`가 바로 확인합니다.
- 금액 = 단가 × 수량, 공급가액 = 금액의 합, 부가세 = 공급가액의 10%, 합계 = 공급가액 + 부가세
- 고객사 · 담당자 · 용역명 · 품목 · 수량 · 단가가 확정된 요청 기록(`outputs/_requests/`)과 같은지, 상호가 `data/company.md`와 같은지, 날짜 모양이 맞는지
- 과업지시서의 계약금액이 견적서 합계와 같은지

틀리면 이유를 AI에게 돌려보내고, AI는 고쳐서 다시 저장합니다. 직접 돌려 볼 수도 있습니다.
```bash
node scripts/check.js
```

### MCP 연결 예시 (이 킷에는 설치하지 않음)
MCP는 AI에게 바깥 도구를 이어 주는 연결선입니다. 실습에는 필요 없고, 회사에서 쓸 때 이렇게 붙입니다.
- **구글 드라이브**: claude.ai 설정 → 커넥터에서 Google Drive를 연결하면 "드라이브의 최신 단가표로 견적서 만들어줘"처럼 쓸 수 있습니다.
- **노션**: 같은 곳에서 Notion을 연결하면 "노션 고객 페이지의 요청 사항으로 견적서 만들어줘"가 됩니다.
