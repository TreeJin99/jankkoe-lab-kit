# 잔꾀 연구소 실습 킷

메일 한 통을 주면 AI가 **견적서 → 과업지시서 → 결과보고서**를 한글(hwpx) 파일로 만들어 주는 실습 폴더입니다.
가상 회사 「새벽웹스튜디오」가 고객 「바다상사」의 홈페이지 리뉴얼 요청을 받은 상황입니다.

> 회사·고객·금액·연락처는 모두 실습용 가상 정보입니다.

---

## 1. 받기

**방법 A. ZIP으로 받기 (처음이면 이쪽)**
1. 이 페이지 위쪽 초록색 **Code** 버튼을 누릅니다.
2. 맨 아래 **Download ZIP**을 누릅니다.
3. 받은 ZIP 파일을 풀면 `jankkoe-lab-kit-main` 폴더가 생깁니다.

**방법 B. git으로 받기**
```bash
git clone https://github.com/TreeJin99/jankkoe-lab-kit.git
```

## 2. 준비

| 필요한 것 | 확인 방법 |
|---|---|
| Claude 데스크톱 앱 (Pro 이상) 또는 Claude Code | 앱 왼쪽 위에 **Code** 탭이 보이면 됩니다 |
| Node.js 20 이상 | 터미널에서 아래 첫 줄. 없으면 https://nodejs.org 에서 LTS 설치 |
| 한글 문서 도구 kordoc | 터미널에서 아래 둘째 줄. 처음 한 번은 내려받느라 1~2분 걸릴 수 있습니다 |
| (윈도우만) Git for Windows | Claude Code가 윈도우에서 쓰는 도구입니다. 없으면 https://git-scm.com 에서 설치 |

```bash
node -v
npx -y kordoc --version
```
`v20` 이상, 그리고 `4.` 으로 시작하는 숫자가 나오면 준비 끝입니다.

## 3. 열기

1. Claude 앱에서 **Code** 탭을 누릅니다.
2. 폴더 선택에서 받은 `jankkoe-lab-kit` 폴더를 고릅니다.

## 4. 실습: 이 문장 그대로 입력

차례로 하나씩 입력하고 끝날 때까지 기다립니다. (한 번에 1~2분)

```text
받은메일 폴더의 메일로 견적서 만들어줘
```
```text
방금 만든 견적서로 과업지시서 만들어줘
```
```text
작업일지로 결과보고서 만들어줘
```

`결과/` 폴더에 `견적서_바다상사.hwpx` 같은 파일이 생기면 성공입니다. 한글(한컴오피스)로 열어 보세요.
맞는 금액: 공급가액 4,950,000원 + 부가세 495,000원 = **합계 5,445,000원**

## 5. 더 해 보기

**슬래시 명령** (스킬을 바로 부르기)
```text
/견적서
```
```text
/과업지시서
```
```text
/결과보고서
```

**팀원(에이전트) 부르기**
```text
검수담당한테 결과 폴더 검사시켜
```

**규칙·자료 바꾸기**
```text
단가표에 "SNS 연동 1식 300,000원" 품목 하나 추가해줘
```
```text
앞으로 견적서 유효기간은 30일로 CLAUDE.md에 추가해
```

**우리 회사 양식으로 바꾸기**
1. 우리 회사 견적서 hwpx를 `양식/` 폴더에 넣습니다. (예: `양식/우리견적서.hwpx`)
2. 이렇게 말합니다.
```text
양식 폴더의 우리견적서.hwpx를 앞으로 견적서 양식으로 쓰게 견적서 스킬을 고쳐줘
```

**ChatGPT Codex에서 쓰기**
같은 폴더를 Codex로 열면 `AGENTS.md`와 `.agents/skills/`를 읽습니다. 스킬은 `$견적서`처럼 부릅니다.

## 6. 폴더 안에 있는 것

| 하네스 요소 | 위치 | 하는 일 |
|---|---|---|
| 회사 규칙 | `CLAUDE.md` | AI가 일하기 전에 먼저 읽는 우리 회사 규칙 (부가세 별도, 쉼표, 금지 정보 등) |
| 회사 규칙 (Codex용) | `AGENTS.md` | `CLAUDE.md`와 같은 내용 |
| 룰 | `.claude/rules/hwpx.md` | `양식/`·`결과/` 파일을 만질 때만 읽는 한글 문서 규칙 |
| 스킬 (레시피) | `.claude/skills/` | 견적서 · 과업지시서 · 결과보고서를 만드는 5단계 순서 |
| 스킬 (Codex용) | `.agents/skills/` | `.claude/skills/`와 같은 내용 |
| 에이전트 (나만의 팀) | `.claude/agents/` | 견적담당 · 문서담당 · 검수담당 |
| 훅 | `.claude/settings.json`, `.claude/hooks/check-result.js` | 파일을 저장할 때마다 `결과/`의 새 hwpx를 자동 검사 |
| 받은 메일 | `받은메일/` | 고객이 보낸 메일 |
| 자료 | `자료/` | 단가표, 작업일지 |
| 양식 | `양식/` | 회사 한글 양식 3종 (빈칸) |
| 결과 | `결과/` | 완성된 문서가 저장되는 곳 |

### 훅이 하는 일
AI가 파일을 저장하거나 명령을 실행한 직후, `결과/`에 새로 생기거나 바뀐 hwpx가 있으면 `kordoc validate`로 한글 파일 구조를 검사하고 `[결과 검사] 견적서_바다상사.hwpx: 통과`처럼 짧게 알려 줍니다. 문제가 있어도 작업을 멈추지 않고 경고만 합니다.

### MCP 연결 예시 (이 킷에는 설치하지 않음)
MCP는 AI에게 바깥 도구를 이어 주는 연결선입니다. 실습에는 필요 없고, 회사에서 쓸 때 이런 식으로 붙입니다.
- **구글 드라이브**: claude.ai 설정 → 커넥터에서 Google Drive를 연결하면 "드라이브의 단가표 최신본으로 견적서 만들어줘"처럼 쓸 수 있습니다.
- **노션**: 같은 곳에서 Notion을 연결하면 "작업일지를 노션 프로젝트 페이지에서 읽어서 결과보고서 만들어줘"가 됩니다.
